# Panduan Pengguna Keylox Desktop

Keylox Desktop adalah editor video berbasis AI yang berjalan di perangkat Anda. Panduan ini menjelaskan fitur dasar tanpa jargon.

## Impor media
- Klik **Impor** atau seret file ke panel media.
- Mendukung video (mp4, mov, mkv, avi, webm), audio (mp3, wav, aac), gambar (png, jpg, jpeg, gif).

## Timeline
- Klip dapat digeser, dipotong (trim), dibagi (split), dihapus.
- Multi-track: video, overlay, teks, audio.
- Snap dan zoom tersedia.

## Teks & caption
- Tambah teks manual di Inspector → tab Text.
- Caption otomatis (mock) tersedia di panel AI.

## Filter & color grading
- Inspector → tab Filter: brightness, contrast, saturation, hue, blur, grayscale, sepia.
- Transform: rotasi, flip, crop, scale.

## Audio
- Volume, mute, pan, fade in/out, waveform.

## Export
- Tombol Export → pilih format/resolusi/fps/bitrate.
- Centang "Seluruh timeline (multi-clip)" untuk export semua klip track pertama jadi 1 MP4.

## API Key (BYOK)
- Settings → AI Provider: masukkan API key provider pilihan Anda. Key disimpan terenkripsi di OS (safeStorage), tidak pernah ke cloud Keylox.

## Privasi
- Mode local-only / standard / cloud. Lihat PRIVACY.md.
